# Zrzuty do dokumentacji forka

W `gotowe/` znajduje się 10 pełnych zrzutów 16:9 z Android TV, dwa wycinki szczegółów, kolaż 3 × 2 i dwa warianty planszy — razem 15 plików. Każdy plik jest w WebP, ma szerokość 1600 px i zajmuje mniej niż 400 000 bajtów. Pełne zrzuty mają rozmiar 1600 × 900 px; układ launchera i dok pozostają w całości w kadrze.

| Plik | Zawartość |
| --- | --- |
| `home.webp` | Pełny ekran główny z trzema kafelkami i dokiem aplikacji |
| `matches.webp` | Pełny ekran z oknem meczów: lista i duży podgląd |
| `matches-tile.webp` | Wycinek lewego kafelka meczów z ekranu głównego |
| `most-watched.webp` | Pełny ekran z oknem JustWatch dla Polski |
| `weather.webp` | Pełny ekran z panelem pogody, z zamazaną miejscowością |
| `wallpaper-settings.webp` | Ustawienia tapet i ulubionych |
| `screensaver-settings.webp` | Ustawienia wygaszacza |
| `widget-settings.webp` | Ustawienia kafelków |
| `goal-notification.webp` | Pełny ekran z przykładową plakietką gola i dokiem |
| `goal-badge.webp` | Wycinek przykładowej plakietki gola |
| `setup-mode.webp` | Kreator: tryb nadawania uprawnień |
| `screensaver-1.webp` | Wygaszacz: futurystyczne miasto nocą |
| `preview.webp` | Fioletowa galeria 3 × 2: ekran główny, mecze, JustWatch, pogoda, gol i wygaszacz |
| `showcase.webp` | Główna plansza z czterema widokami: duży ekran główny z pełnym dokiem, okna meczów, filmów i pogody oraz plakietka gola; cienkie świetlne krawędzie 2–3 px, miękkie cienie i fioletowa oprawa |
| `showcase-immersive.webp` | Alternatywna plansza: duży ekran pod lekkim kątem, oszczędny nagłówek Liquid Glass i płynne szklane formy w tle |

Powitanie zachowuje słowa „Dzień dobry”, ale prywatną nazwę zastępuje regularna, zaokrąglona maska z rozmytym i pozbawionym detali środkiem oraz delikatną krawędzią. Tak samo ukryto miejscowość w kafelku i panelu pogody oraz wyłącznie podpis Premium Smart TV. Zgodnie z późniejszą decyzją właściciela wszystkie ikony, podpis Kick TV MOD, pozostałe nazwy aplikacji oraz cały dok pozostają widoczne. Nazwy drużyn, meczów i serwisów pozostawiono. W widocznych częściach gotowych obrazów nie znaleziono nazw kont, sieci Wi-Fi ani adresów IP.

Zrzuty zanonimizowano i złożono lokalnie. Osobne dekoracyjne tła wygenerowano narzędziem `imagegen`, bez przekazywania zrzutów ani danych prywatnych; pliki i dokładne prompty są w [oprawa/](oprawa/README.md). Interfejs na obrazach jest prawdziwy i nie był generowany przez AI. Główna plansza łączy cztery widoki i plakietkę gola; duży ekran zachowuje proporcje 16:9 i pełny dok. Oprawa okien składa się z cienkiej krawędzi, miękkiego cienia i słabej fioletowej poświaty. Okna meczów, filmów i pogody są wycinkami kompletnych okien ze zrzutów, bez przebudowy interfejsu. Panele i podpisy nie zasłaniają doku głównego ujęcia. Do typografii wykorzystano dołączony krój Inter. Osobne zrzuty pozostają płaskimi, pełnymi kadrami 16:9. Kolaż pokazuje sześć pełnych ekranów. Wycinki kafelka i plakietki powiększono do wymaganych 1600 px; w README są wyświetlane jako mniejsze ilustracje. Usunięto metadane obrazów. Surowe pliki są ignorowane przez Git i pozostają na dysku.

Zdjęcia w tle, grafiki filmów i herby zachowują prawa swoich właścicieli.

Zdjęcia dodanych scen i zrzut z czerwonym Lamborghini pozostają poza repozytorium.
